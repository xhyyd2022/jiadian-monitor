# 在线素材（online/）

这个目录放**在线素材的配置**：一条在线素材 = 一个 `.toml` 文件。
文件名（去掉 `.toml`）就是它的 id，界面里显示的是文件里的 `title`。

- 不想要某条在线素材：在程序「在线」页删除，或直接删掉对应的 `.toml`。
- 手改 `.toml` 后回到「在线」页点「刷新」即可重新读取；正在运行的画面不会自动切。
- 这个目录由程序自动创建，放在 `jiadian-monitor.exe` 同级。

## 文件格式

```toml
title = "天气面板"
description = """
可选的说明：给这个在线页面写点备注，只有界面里能看见。
"""

[v1p]
url = "https://example.com/panel/v1p/index.html"

[v2]
url = "https://example.com/panel/v2/index.html"
```

- `title` 必填，1–40 个字符。
- `description` 可选，最多 2000 字符，仅界面展示。
- `[v1p]` / `[v2]` 至少写一个；`v1p` 是 320×170（V1PRO），`v2` 是 320×240（V2）。
  当前设备是哪个尺寸，程序就加载哪个 URL；缺对应尺寸时「确定」按钮会禁用。
- `url` 只允许 `https://` 开头；本机调试可用 `http://localhost` 或 `http://127.0.0.1`。

## 在线页面怎么写

- 页面自己用 `fetch('http://127.0.0.1:8766/metrics')` 等接口取数（可用
  `?__api=8766` 参数读取端口），**不需要**实现 `__setSlot`。
- 视口按 320×170 / 320×240 设计；页面放在 https 网站上，程序用隐藏 WebView2 加载。
- 页面会访问本机回环接口，浏览器安全策略对 localhost 有豁免；但页面里不要放密钥，
  不要引用不可信的第三方脚本。
- 只添加你信任的网站；在线页面属于远程代码，程序只负责加载和抓帧，不校验其内容。

指标名、单位、外设数据格式见程序「素材」页的提示词与文档；本仓库
`MONITOR_METRICS.md` 是占位符字典。
